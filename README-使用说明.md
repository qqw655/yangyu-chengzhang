# 洋芋养成

把抖音火种泰勒《情感原始人》等课程的核心观点，与顶级文献、书籍、研究逐条对照后筛出来的成长课。每天一课，打卡记录自己的成长，像一颗土豆慢慢长大。

## 内容怎么来的

31 张基础卡片 + 34 张扩充卡片（两性真相 10 / 男性成长 12 / 吸引力科学 12），每张都标注了来源，原则是：

- **有研究/书籍支持的**：情绪稳定（Buss 1989 跨文化择偶研究）、真诚与倾听（Rogers 共情倾听、非暴力沟通）、成长心态（Dweck《Mindset》）、自我同情（Neff 2003）、习惯养成（Clear《原子习惯》、Fogg《Tiny Habits》）、依恋理论（Bowlby & Ainsworth）、曝光效应（Zajonc 1968）、相像性吸引（Montoya & Horton）等
- **与文献对照后修正的泰勒观点**：野兽绅士（主导-亲和研究）、钝感力（复原力/情绪调节）、精神力量（自我决定理论）、课题分离（阿德勒）、认同感双刃剑、放下英雄主义执念等
- **明确标为误区的**："潜意识操控""话术套路""完美男性"等营销话术，证据弱，别花钱学

另外还有一个独立的**幽默聊天**板块（21 张卡片），讲怎么说话幽默风趣：理论部分依据 Bressler 2006（幽默生产与择偶）、Martin 2007（幽默四风格）、Keltner 2001（调侃即调情）、Huang 2015（嘲讽的边界）等；每个理论都配了"兄弟局"（男生间互损、吹牛、接梗）和"暧昧局"（轻推、推拉、读信号）的真实对话案例，练完直接能用在聊天里。

幽默板块里还有两个每日工具：

- **今日金句**：每天一句现成的撩人/接梗话（24 句轮换，可"换一句"），复制就能用
- **撩人练习**：每天从"暧昧局"里抽一条，练完点打卡，记录连续练习天数——依据是刻意练习（deliberate practice）理论，每天一小练比背十句话有效

## 功能

- **今日一课**：每天自动推送一张卡片，可"换一课"随机刷新
- **目录**：底部"目录"页列出全部卡片（基础 + 扩充 + 幽默），按分类分组、显示总数，点标题直接打开完整内容
- **专栏**：底部"专栏"页是"最受欢迎的男人"全面刨析——身体条件（身高/体脂/肩腰比/面部/声音）、个性原则（情绪稳定/威望路径/幽默/边界）、行为社交（回应/倾听/自我表露），附国内婚恋大数据与误区清单
- **幽默板块**：底部"幽默"页每天推一个梗，按理论 / 兄弟局 / 暧昧局 / 误区分类，每张卡带真实对话案例和练习
- **今日金句 + 撩人练习打卡**：每天一句现成金句可复制；每天一条暧昧局练习，练完打卡累计天数
- **穿搭板块**：按目标身材（177-178cm / 70-72kg / 体脂12-14%）给出精确尺码规则（衣长 68-72cm、裤长、鞋高 ≤3cm、配色 70/30）+ 五个场景完整穿搭（日常/约会/夜场/正式/运动），标注研究依据与误区（Elliot 2010 红色效应、Vrij 1997 黑色感知、Fetscherin 2020 整洁度等）
- **知识库**：31 张卡片，按内在力量、边界与真诚、情绪稳定、沟通与倾听、关系经营、吸引力真相、行动与习惯、误区提醒分类浏览
- **搜索**：按标题 / 来源 / 关键词搜索
- **收藏**：重点内容一键收藏，随时回看
- **完整卡片**：点卡片看完整内容（含来源、内容、行动），可一键复制
- **打卡**：每天打卡，记录连续坚持天数
- **备份**：数据可导出 JSON、可导入，换手机不丢记录

## 怎么装到 iPhone 桌面

1. 打开 [Netlify Drop](https://app.netlify.com/drop)，先登录免费账号（不登录发布的网址是临时的，可能过阵失效）
2. 把整个 `洋芋养成App` 文件夹拖进去，得到一个 `https://xxxx.netlify.app` 网址（必须是 https 开头）
3. 用手机 Safari 打开网址 → "分享" → "添加到主屏幕"
4. 桌面出现"洋芋养成"图标（一颗长大的洋芋），点开即可全屏使用，断网也能用

详细图文步骤见同目录 `安装说明.html`。

## 打不开怎么办

- 主屏幕图标必须指向网上 https 网址，不能指向电脑本地文件
- 检查网址是不是 https:// 开头、有没有复制错
- 切换 Wi-Fi / 手机流量再试

## 以后想更新

把最新的 `洋芋养成App` 文件夹重新拖进 Netlify（登录状态下拖，网址可保持不变），手机 Safari 重新打开网址；图标不更新就删掉重新添加一次。打卡和收藏数据存在手机本地，不会丢。
